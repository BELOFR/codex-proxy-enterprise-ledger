- 构建：Rust 1.99.1、Node.js 24、pnpm 11.25.0；精确依赖见两份锁文件。
- Docker 镜像：`rust:1.99.1-bookworm`，本次镜像摘要 `sha256:e6f2cff35d0f309acf8433b4f05878ed77092602c5065cc81801177da0bb3a9c`。
- `readelf` 显示最高必需 GLIBC 符号为2.34，动态依赖为 libc、libm、libgcc_s；Debian 12 下运行通过。不适用于 Alpine/musl 或 Windows，其他发行版尚未逐一验证。

## 验证边界

尚未安装到用户实际运行的 Codex Proxy RS，也未在完整宿主 UI 中验收上传、启用和生产数据读取。当前验证为真实插件进程与模拟公开宿主协议、沙箱页面的集成测试；清单声明 `>=3.49.0, <4.0.0`，未来宿主版本的兼容性仍须实测。

尚未使用 Excel/WPS 应用打开文件；已验证 XLSX ZIP 内容、文本单元格和完整请求记录。实际 HTTPS 宿主的链接确认、真实多管理员并发、大规模数据及生产环境断电恢复尚未实测。

本版通过宿主管理员入口使用，没有独立财务／业务／老板账号及部门权限隔离。付款依赖人工登记或 CSV，未接银行、发票或供应商账单接口。报表只包含原生请求，不包含无明细的外部聚合贡献。月结及查询容量限制见 README。

完整构建命令见 README。`protocol_check.py --serve` 只在127.0.0.1启动临时测试宿主，默认端口8769；`GET /__shutdown` 关闭测试宿主及插件子进程。请勿把这个模拟宿主用于生产。
