# 核算口径与容量参考

[返回 README](../README.md) · [完整使用流程](usage.zh-CN.md)

## 数据来源

宿主保存原生请求事实、统计资格、模型、Token 及历史用量金额。插件使用固定提交的公开 SDK 读取数据，不直接读写宿主业务数据库。插件保存有效期归属、付款、费用池、预算及月结版本。

只扫描当前仍保留的原生请求，不包含没有请求明细的外部聚合贡献。宿主默认保留31天，长期报表需要提前调整宿主保留设置。数据被清理、尚未落库或从未采集时，插件无法补造。

一次扫描提供固定的数据锚点，收到 `complete=true` 后才生成完整报表；超时、不完整、重复请求、越界记录或锚点变化都会拒绝生成。汇总与 Excel 从同一批完整记录计算，导出不会重新扫描。页面仅传回前100条预览，Excel 包含完整扫描结果。

## 请求与 Token

- 请求数继承宿主的 `request_counted`，交付用量继承 `usage_counted`，避免恢复／预热等排除项重复计入。
- 输入包含缓存 Token，输出包含推理 Token；缓存和推理不能再次加进总 Token。
- 请求数和完整交付数是不同口径，不能仅按最终成功／失败标签替代宿主统计资格。
- 未知 Token／费用与已知零分别保存，汇总旁显示缺失数量。
- 请求按开始时间及报表时区归属，使用当时有效的人员、部门、项目映射。稳定 Key ID 不等于明文 Key。

## 三种金额分开看

| 口径 | 含义 |
| --- | --- |
| 上游报告 | 请求当时保存的 Provider 报告费用，保留币种 |
| 本地估算 | 请求当时保存的估算费用，不用当前价格覆盖历史 |
| 实际付款 | 人工或 CSV 登记的现金流，按付款日汇总 |
| 整期分摊基数 | 经确认属于所填归属期间的管理费用 |
| 本期基数 | 整期基数按归属期间与查询范围重叠的日历天比例计算 |
| 已分摊／未分摊 | 本期基数的分配结果，每个币种分别满足两者相加等于本期基数 |

用量金额、现金流和分摊费用不能直接相加，成功交付用量不等于 Key 计费账本或供应商结算单。台账不代替正式会计凭证。

充值的分摊基数必须零，消费结算另记；退款用负数并关联同池同币种的原付款，明确归属期间。付款ID及非空「供应商＋凭证编号」唯一，重复导入拒绝，任何一行无效时整批不保存。

支持付款／预算币种 CNY、USD、EUR、GBP、HKD、JPY，JPY 为整数精度，其他为两位小数。不同币种分别展示，没有自动汇率换算。

## 分摊

账号ID、Key ID及 Provider 条件共同匹配。同一请求匹配多个池时拒绝报表；空筛选的非人工池匹配全部请求，人工池空筛选时只分付款、不认领请求。

- Token 权重：要求池内合格请求 Token 齐全，确认不同模型采用同权重符合业务约定。
- 金额权重：要求费用齐全、权重币种一致，不能将不同币种的金额直接作为同一组权重。
- 人工比例：正的十进制百分比字符串，合计100。

无合格用量、零分母或缺失权重时整池保留未分摊，不剔除异常后分给其他部门。非人工权重使用本次查询中、同时落在对应付款归属期间内的合格用量，因此不同查询范围的分配权重可能不同。

金额使用十进制计算，按最大余数及稳定请求顺序分配最小币种单位，避免极小金额产生反向分摊。退款保留负号。

## 预算和月结

部门与项目预算按名称精确匹配，同币种已分摊支出与本期预算比较，预算也采用日历天比例。零预算时比例不适用，未分摊费用不塞入某个部门预算。

月结保存当时的报表、请求和配置，后续调岗、付款或规则修改不会改写历史。重新打开月结不扫描；同一期间再次保存须填调整说明。月结整体与当前配置使用单条压缩 CAS 记录原子保存，冲突或超限失败不会删除旧月结。

## 容量和缓存

| 项目 | 上限／行为 |
| --- | --- |
| 查询 | 1～366天，最多50,000条原生请求 |
| 配置 | 1,000条归属、100个费用池、2,000笔付款、1,000条预算；配置 JSON 最多512 KiB |
| 在线月结 | 最多24个版本 |
| 整体持久状态 | gzip＋base64 后单条256 KiB；解压后最多8 MiB，以先到为准 |
| 报表缓存 | 最多4个，各15分钟 |
| 待下载 Excel | 最多4个，各最多16 MiB，保留10分钟 |
| 下载票据 | 两分钟内有效，文件成功交付一次后删除 |

压缩率取决于真实内容，24个版本并不是容量承诺。需要时缩小查询范围，先另行保存 Excel，再确认移除旧归档。付款和当前配置不会随着月结移除，但被删月结版本无法恢复。

文件和短期缓存位于进程内，重启会清除未下载文件。HTTPS 通过宿主确认打开下载，HTTP 复制一次性链接至新标签页。链接按财务文件保管。

Excel 使用显式字符串单元格保存用户文本，不将 `=` 等开头的名称当作公式；超出 Excel 可靠数字精度的数值写为文本。表格是值快照，编辑后不自动重算插件结果。
